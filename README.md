# A PUC também é nossa

Site estático (Next.js, `output: "export"`) com animações Remotion (`@remotion/player`).

- `npm run dev` — desenvolvimento
- `npm run build` — gera `out/` (hospedagem estática)
- `remotion/` — composições (HeroBackdrop, PautasReel, Countdown, SpeakerTimer)
- `components/content.tsx` — textos e data do ato (`EVENT`)
- `legacy/` — versão HTML pura anterior
